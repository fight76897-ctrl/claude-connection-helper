# Claude 连接助手实施记录

> 此文件是 0.1.0 的历史实施记录。当前协议、功能与验证结果以 README.md 和 validation.md 为准。

## 目标与架构

交付 Windows 桌面助手，将专用浏览器、Code、Science 及明确配置的 API 工具按 **本地 VPN → HTTP 住宅代理** 顺序转发，并提供按程序路径的直连阻断。

Electron 45.0.0 提供界面及隔离浏览器；Node.js 内置 HTTP / NET / TLS 模块实现两级 CONNECT；Windows 防火墙负责阻断所选可执行程序的非回环出站。`@electron/packager` 20.3.0 生成 Windows x64 目录包。

## 持续有效的约束

- 不自动变更系统代理，不结束用户的运行中研究任务。
- 密码只在本地输入；日志不记录认证头、请求正文或 Token。
- 防火墙规则保留回环；其他本地代理仍可使用。
- 仅保护已选择的程序路径。新增子进程及客户端更新后需核对范围。
- 出口 IP 核对为手动操作；固定出口、防火墙规则和本地测试都不构成防封保证。
