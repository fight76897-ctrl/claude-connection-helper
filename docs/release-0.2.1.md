# v0.2.1 Windows 安装包

## 下载与安装

下载 `ClaudeConnectionHelper-0.2.1-Setup-x64.exe`，运行安装向导。安装器提供桌面和开始菜单快捷方式，适用于 Windows x64。也可使用 `SHA256SUMS.txt` 核对下载文件。

安装包未做代码签名。安装后请填写自己的本地 VPN 和住宅代理参数；发布包不包含任何个人代理账号、密码或登录数据。ProxyBridge 需自行安装，当前集成针对 4.2.0。

## 功能

- 本地 HTTP VPN → HTTP CONNECT / SOCKS5 住宅代理的两级连接。
- 启动时核对预期静态 IP 和美国归属；检查失败时关闭助手代理及现有隧道。
- Claude 网页、Desktop、Code 和 Science 入口；每分钟追踪已安装客户端版本和路径。
- 按程序路径的 Windows 防火墙保护、独立 ProxyBridge 配置和连接元数据记录。
- 修复把 SOCKS5 住宅端口当成 HTTP CONNECT 使用导致的提前断开问题。

## 验证

- 43 项自动化测试通过。
- 从本次安装包中提取程序，在隔离空配置下验证实际 EXE、界面、IPC 和客户端版本发现。
- 安装包内应用源码与当前运行源码核对一致；应用 ASAR 有 22 个条目，未包含测试目录、开发依赖、用户配置、Cookie、凭据或诊断日志。
- 一次真实 SOCKS5 两级出口查询通过，IP 与预期一致且国家为 US。各客户端登录、长期稳定性及真实防火墙与 ProxyBridge 的共同运行仍需单独验收。
- 未在开发机器执行安装器的实际安装／卸载流程，避免影响正在使用的助手、快捷方式和防火墙。

## 使用边界

出口周期检查存在检测延迟，不是逐请求地理验证。新客户端路径需要补齐保护规则；阻断其他本机代理依赖 ProxyBridge 持续运行。此工具不能保证永久防泄漏或账号不被封禁。

安装到新目录后，需重新核对助手自身路径的保护规则。卸载前如需恢复普通联网，请先停止助手和 ProxyBridge，再使用“恢复直连”或 `restore-network.cmd`。卸载器保留用户配置和已有防火墙规则。
