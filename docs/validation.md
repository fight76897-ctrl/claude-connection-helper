自动化使用模拟代理、模拟出口或独立测试配置。测试中出现的 IP 和凭据不代表用户住宅线路。

## 尚需真实线路验收

住宅代理参数已在本机填写，一次 SOCKS5 链路和静态出口检测已通过。以下项目仍需验收：

1. 长时间运行期间的出口稳定性、断线行为及周期检查。
2. Claude 网页版、Desktop、Code、Science 的实际登录、授权回调和业务请求。
3. 管理员授权后，真实防火墙确实阻断所选程序非回环出站；助手停止后规则继续生效，恢复工具仅移除本助手规则。
4. ProxyBridge 与真实防火墙共同运行时的透明转发、UDP／其他回环阻断及故障行为。
5. 客户端升级后的新路径被发现、重新保护并在 ProxyBridge 中重新加载。

## 实际边界

- 成功检查后约 **30 秒**再次查询，单次超时 **25 秒**。周期检查存在发现延迟，不是逐请求的国家验证；查询服务的国家结果也不是住宅属性证明。
- 保护按选定程序完整路径生效，未选中的路径、未知子进程及其他服务代发流量需要另行核对。系统 DNS 可能不属于选定客户端进程。
- 防火墙持续阻断非回环出站，但允许全部回环；ProxyBridge 运行时才补充 UDP 和其他回环阻断。ProxyBridge 停止后不能保证阻止其他本机代理。
- 透明转发可能被防火墙先行拒绝，兼容性未实机确认；支持代理的客户端应明确配置助手代理。
- ProxyBridge 的连接记录表示路由尝试，进程运行状态不证明转发成功。元数据观察不会自动生成允许规则。
- 自动扫描不负责下载或安装客户端升级。固定出口和本地测试通过都不能保证账号不被封禁。
