# 固定出口与桌面登录增量计划

目标：在现有助手上补普通 Claude Desktop、受限登录回调、强制静态美国出口检查和 ProxyBridge 连接记录。

1. 桌面入口：`launchers.cjs` / `browser.cjs` 提供路径发现、固定代理启动与受信 `claude://` 回调。验证：路径身份和回调来源测试，不启动正在运行的客户端。
2. 出口门禁：`exit-watch.cjs` 通过相同两级隧道查询 IP/国家；`proxy.cjs` 初始拒绝业务流量。预期 IP 必填；首次通过才放行，每 30 秒检查，失败关闭已有隧道。验证：未检查零上游连接、非美国/不匹配/错误断流与取消后的旧结果丢弃。
3. ProxyBridge：独立配置，先阻断目标程序 UDP 和非助手回环连接，再代理 TCP；保留用户 Default。独立 CLI 生命周期和元数据记录。验证：配置 schema、规则顺序、安全引号、日志解析和进程收尾。透明拦截与防火墙在真实客户端上的兼容性保留为实机验收项目。
4. `main.cjs` / preload / renderer 接线、手动选择客户端、明确显示监测和 PB 状态；文档说明检测间隔、DNS/系统浏览器/共享运行时范围以及退出 PB 的失效边界。
5. 完整测试、真实 Electron 界面冒烟、打包与实际 EXE 冒烟；住宅凭据仅由用户本机输入，未提供前不宣称真实线路或账号登录已验证。

约束：不修改系统代理，不结束现有研究任务，不覆盖 ProxyBridge 默认配置，不记录请求内容/登录令牌，不把路由事件视为已证明的美国出口。现有防火墙负责持久阻断所选程序公网直连；回环阻断依赖 PB 运行，不能宣称驱动级永久锁定。
